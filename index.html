🆔Lấy ID phòng chat

  1. Thêm bot vào tab BOT
  2. Thêm bot vào nhóm / kênh Telegram
  3. ID tự hiện ở tab PHÒNG CHAT — hoặc gõ /id trong nhóm

📤Gửi file qua bot

Upload ảnh, video, tài liệu (tối đa 50MB) rồi gửi thẳng vào phòng chat. Thành viên cũng có thể gõ /file để tự nhận file từ kho.

➕Thêm bot

🎮Slash commands

/help /id /star /file /aov /mod /ff /ban /unl

Để /ban và /unl hoạt động, bot cần quyền quản trị phù hợp trong nhóm.

📡Radar ID tự động
